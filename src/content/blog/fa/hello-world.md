سلام! این اولین نوشته‌ی وبلاگ من است. می‌خواستم سایتی داشته باشم که وقتی کسی بازش می‌کند، همان لحظه‌ی اول حسش کند.

## این سایت با چه ساخته شده؟

- **Astro** برای ساختن صفحه‌های استاتیک و سریع
- **Three.js** و یک شیدر GLSL برای کره‌ی مایعی که پشت صفحه می‌بینی
- **GSAP** و **Lenis** برای انیمیشن‌ها و اسکرول نرم

## چند ترفند مخفی

کلید `Ctrl` و `K` را با هم بزن تا به هر جای سایت بروی. کلید `` ` `` هم یک ترمینال باز می‌کند؛ آنجا بنویس `help`.

```js
// هر پست فقط یک فایل Markdown است
const post = { title: 'سلام دنیا', lang: 'fa' };
```

> نوشتن، بهترین راه برای فهمیدن است.

درباره‌ی طراحی رابط، تایپوگرافی فارسی و چیزهایی که حین ساختن یاد می‌گیرم می‌نویسم.
